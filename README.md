# Catcon · 蜜柑

一只住在 Windows 桌面上的 32 × 32 像素橘白猫。透明背景、托盘常驻、鼠标互动，随前台应用变化的陪伴动作，还有一小块可以种花的像素花圃。

## 启动

推荐双击 `dist/Catcon-1.8.0-Setup.exe` 安装：自动释放完整文件、检查 .NET 4.8、创建启动和卸载入口。默认安装到当前用户目录；已具备运行库时无需联网和管理员权限，缺少时调用内嵌的微软 Web 安装程序补装，需要联网及管理员授权。后续直接运行新版安装包即可保留设置原位升级，旧配置会先备份；同版本支持修复安装，并阻止降级覆盖。参见 [安装与升级说明](docs/INSTALLATION.md)。

下载或复制 `dist/Catcon-1.8.0-win.zip`，**完整解压**后双击 `Catcon.exe`。也可以直接运行本仓库中的 `dist/Catcon-1.8.0/Catcon.exe`。请保留 exe 同级的 `assets`、`config` 文件夹。程序无需安装、管理员权限、Python、Node 或联网。升级时先从托盘退出旧版，再打开新版；已有位置和设置会保留。

运行环境：Windows 10 / 11，.NET Framework 4.8（Windows 10 较新版本及 Windows 11 通常已内置）。使用 Windows 自带的 .NET Framework 编译器，输出为 AnyCPU，可在 x64 / x86 系统运行。当前安装包未作代码签名。

首次打开会显示「蜜柑的小窝」。关闭小窝后，猫咪继续留在桌面。托盘图标可能在系统托盘折叠区。

## 和猫相处

| 操作 | 结果 |
| --- | --- |
| 单击猫咪 | 摸头、冒出爱心 |
| 双击猫咪 / 双击托盘 | 打开小窝 |
| 按住猫咪拖拽 | 移动位置；松开后坐好 |
| 右键猫咪 / 托盘 | 喂食、喝水、动作图鉴、暂停、置顶、退出 |
| 选择「追鼠标」 | 3 秒后锁定鼠标位置，跑近后蓄力、向前跃出并以前爪落到目标；不改变鼠标、不发送点击 |
| 鼠标快速接近 | 炸毛；24 秒内连续三次受惊会鸡母蹲 |
| 鼠标在附近停留 | 5 秒后挪开；可在设置关闭自主移动 |
| 猫咪不见了 | 托盘 → 把猫找回来 |

画布原生尺寸 **32 × 32**，默认 4 倍整数缩放（128 × 128 的透明窗口，猫咪可见部分更小），设置支持 2～6 倍。透明区域不阻挡下面的窗口；猫咪不会因普通互动抢走键盘焦点。恢复上次位置、显示大小和设置。

游戏情境默认启用安静陪伴：不自主移动、不响应鼠标惊吓；手动发起的追鼠标仍可使用。安全桌面、锁屏和独占全屏应用有系统限制；游戏推荐使用无边框窗口模式。

## 蜜柑的花园

桌面上另有一块 **112 × 80** 的像素花圃，和猫咪是各自独立的分层窗口：一道木栅栏、一条草地、一块翻好的土，边上是木牌、灯笼、蘑菇、石子、洒水壶，以及一堆没什么用但很好看的小垃圾——花园小矮人、风车、玻璃罩、玻璃弹珠、观景球、橡皮鸭和一串彩灯。栅栏上常停着两只小鸟（会转头、抖尾巴），天上也会不定期飞过两三只。

显示倍数可选 **2.5 / 3 / 3.5 / 4 / 4.5 / 5 / 5.5 / 6 倍**，默认 3 倍（336 × 240 屏幕像素）。所有档位都走按目标尺寸取整的最近邻放大，含 0.5 的档位也是宽度交替的整数像素列，边缘仍然硬，不会糊成一片。

![花园](docs/garden/garden.png)

| 操作 | 结果 |
| --- | --- |
| 单击花圃 | 浇水 |
| 双击花圃 | 打开小窝的「花园」页 |
| 按住花圃拖拽 | 移动位置；松手后吸附回当前工作区 |
| 右键花圃 | 浇水、按品种播种、让蜜柑过来坐坐、打开面板、置顶、收起 |
| 托盘 → 蜜柑的花园 | 显示 / 隐藏、浇水、按品种播种、让蜜柑去坐坐、打开面板与设置 |

透明区域同样不挡下面的窗口；花圃不抢键盘焦点，只在可见像素上响应鼠标。

会自己动的小东西：彩灯依次明暗、风车一直转、蝴蝶绕着苗床飞、栅栏上的鸟每十秒换个姿势、天上的鸟按时间循环飞过、有风时花瓣从开花的植株上飘下来。这些都由当前时间算出来，不写进存档。

### 能种什么

| 品种 | 长成 | 花 |
| --- | --- | --- |
| 猫薄荷 | 20 分钟 | 一串蓝紫色小穗 |
| 雏菊 | 25 分钟 | 白瓣黄心 |
| 迷迭香 | 28 分钟 | 不开花，只长香叶 |
| 小苍兰 | 33 分钟 | 甜香小喇叭 |

### 撒下一包种子

深褐的土上落一粒深色种子是看不出来的，所以撒种这一下给足反馈：三粒种子从槽位上方落下来、土面扬起一小把土屑、嫩芽位置冒出几个绿色的十字光点往上飘，落点再亮起一圈暖黄的光环和一小撮翻起来的新土，正上方还有一枚白色十字闪光往上升一点再散掉——整个动作约 1.6 秒，全部画完不留痕。

同时给文字提醒：气泡里报一句「已经撒下 虞美人，现在还是幼苗。土干了记得浇水。」（4 秒内不重复刷，连撒几包也只提醒最后一次），面板的提示语行在接下来 6 秒里换成同一句，压过「土壤有点干了」「花圃已经长满」这些常规提示。种子落进土里、土屑落回土面就自行消失，不会堆在画面上。

![刚撒下种子](docs/garden/garden-sowing.png)

同一帧的局部 12 倍放大（`docs/garden/garden-sowing-zoom.png`）：可以看清落下的种子、扬起的土屑、绿色的十字光点，以及嫩芽上方那枚白色闪光。

![播种反馈的局部放大](docs/garden/garden-sowing-zoom.png)

### 生长、浇水和分株

植株的进度按品种的成株时间线性推进，画面上分「刚撒下 → 幼苗 → 长叶 / 抽枝 → 现蕾 → 花苞 → 盛开 / 茂盛」几段，茎数、叶片和花会跟着一段段长出来。会开花的品种 55% 现蕾、62% 结出花苞，95% 才算盛开；迷迭香这类不开花的则一路长叶到「茂盛」。

土壤从满到空约 **45 分钟**：

- 湿度低于 **34%**：花圃左上角出现水滴，托盘同时气泡提醒（2.4 秒节流）；生长速度开始打折。
- 湿度低于 **8%**：生长降到 12%，植株同时累积枯萎；枯到满大约 25 分钟，最终只会把生长再拖慢至多 55%，不会掉进度。枯萎的表现是茎、叶、花色往枯黄混，叶片下垂。
- 浇水：湿度回满，枯萎当场减 45%，土上溅起水花粒子。点花圃、右键菜单、面板按钮三个入口等价。

![缺水时的水滴提醒](docs/garden/garden-thirsty.png)

已经盛开、且土壤湿度高于 25% 的植株会自然分株：每分钟每株 7% 概率在旁边空槽里冒出新的一株，品种随机。槽位共 12 个，长满后不再分株，也不能再撒种。

### 风与花瓣

有植株盛开时，每隔 70～210 秒会抽一次 62% 的概率起风，持续 3～7 秒，每秒生成约 11 片花瓣。花瓣从花冠上散出，颜色取该品种的花色，顺着风向飘、带一点横向摆动和加速下坠，最多同时存在 160 片。迷迭香不开花，因此不会产生花瓣。

![起风落花瓣](docs/garden/garden-wind.png)

各品种的生长阶段对照图在 `docs/garden/garden-stages-*.png`。

### 蜜柑会自己来

允许自主移动时，花圃每 150～410 秒有 55% 的概率把蜜柑叫过来：它走（或跑）到开花的植株旁边，随机左右偏一点，坐一会儿再走。右键「让蜜柑过来看看花」和面板上的按钮可以立刻唤一次。摸头、拖拽、扑击等受保护交互进行中时，这次自主来访会推迟十几秒再来，不会把猫从你手里叫走。设置里可以单独关闭「蜜柑偶尔自己走去花园坐坐」。

到了花园不会只是干坐着，落位之后会从中挑一段和花圃有关的动作演一次，演完才转回常规坐姿——坐多久由这段动作自己的时长决定，从 4 秒（打喷嚏）到 14 秒（就地趴下）不等。挑法是先把「当前讲得通的动作」按权重放进一个列表，再等概率抽一个，所以同时满足几个条件时会混着来：

| 动作 | 长什么样 | 出现条件 | 权重 | 演多久 |
| --- | --- | --- | --- | --- |
| `sit_tilt` 歪头看 | 坐着把头偏一偏，像在打量这株是什么 | 有盛开的植株 | 2 | 8 秒（循环） |
| `sneeze` 打喷嚏 | 凑近闻了一下，被花香呛到 | 有盛开的植株 | 1 | 4 秒 |
| `leaf_catch` 接花瓣 | 抬爪接住飘下来的花瓣 | 正在起风且已有花瓣 | 3 | 5 秒 |
| `knead` 踩湿土 | 前爪来回踩，像在给新土按一按 | 土壤湿度 > 50% | 2 | 8 秒（循环） |
| `bug_watch` 看蝴蝶 | 盯着蝴蝶飞，头跟着转 | 配置里有蝴蝶装饰 | 1 | 5 秒 |
| `loaf` 就地趴下 | 直接趴成一团，明显不打算走 | 总是可选 | 2 | 14 秒（循环） |

`loaf` 是保底项，所以土干、没风、花也没开的时候，蜜柑就是过来趴一会儿。挑之前还会用当前皮肤确认这段动画真的存在，缺哪段就换一段——换个皮肤最多是少了某种互动，不会因为缺一个片段而卡住。这一版同时把来访落点从"床中央偏上"改成"某株开花的植株旁边"，看起来更像真的在照看花。

### 存档与小窝

状态存在 `%LOCALAPPDATA%\Catcon\garden.json`：植株品种、槽位、进度、枯萎值和土壤湿度。浇水、播种、退出时立即保存，运行中每 15 秒按需保存。重新启动会按存档时间补算离线时段，**上限 6 小时**，所以隔夜回来是继续长了一点、土也更干，不会一次补满好几天。

小窝的「花园」页：实时预览（3 倍，与桌面窗口同一套渲染）、植物数 / 湿度 / 盛开株数、当前该做什么的提示语（刚撒完种会先报品种）、浇水与唤猫按钮、按品种撒种的下拉框，以及显示窗口、自动来访、2.5～6 倍缩放三个设置。插拔显示器或改分辨率时，花圃和猫咪一起重新吸附回工作区。

## 情境识别

调用 Windows API 获取前台窗口的进程名、窗口标题与范围，补充读取程序的产品名称 / 文件说明；每 2 秒采样、连续 2 次一致才切换情境。只在本地内存中匹配，**不保存窗口标题、不截图、不上传**。产品信息读取失败时继续使用其他可用线索。

| 情境 | 部分内置匹配 | 陪伴动作 |
| --- | --- | --- |
| 写代码 | Codex、WorkBuddy、VS Code、Cursor、JetBrains、Visual Studio、终端；浏览器 GitHub 等 | 监工、敲电脑、踩键盘、编译报错缩一团、睡觉 |
| 看视频 | VLC、mpv、PotPlayer、哔哩哔哩；浏览器 YouTube 等 | 一起看、屏幕里飞鸟伸爪、打哈欠、睡觉 |
| 办公 | Office、WPS、Notion、Obsidian、PDF；在线文档 | 看资料、坐资料上、喝水、打盹、伸懒腰 |
| 浏览网页 | Edge、Chrome、Firefox、Brave 等 | 看书、点头打瞌睡、歪头、玩毛线球 |
| 聊天 | 企业微信 / WXWork / WXWorkWeb / WeCom、微信、QQ、Telegram、Discord、飞书、钉钉、Teams 等 | 竖耳、歪头、问号偷听、哈欠被抓装没事 |
| 玩游戏 | 常见游戏进程；游戏关键词与全屏辅助线索 | 手柄游戏、输了扭头、观察、喝水 |

**1.2.0 新增智能补充识别**：先匹配明确应用规则，未命中时再按进程名、产品信息和标题中的关键词分组加权。同组重复词只计一次，相同词出现在多个来源也不会重复堆分；置信分不足、前两类得分太接近或读取不到前台信息时回到 `idle`。全屏只是弱线索，不能单独把未知应用判为游戏。明确的视频网站等规则仍优先于泛化关键词。

小窝「设置」可单独开关「智能补充识别」。默认最低置信分为 68%，同时要求足够的证据得分和类别分差；这是启发式置信分，不是经过统计校准的概率。已知浏览器没有具体内容线索时仍归「浏览网页」，强线索冲突时会放弃判断。阈值、关键词、证据权重均在 `config/classifiers.json` 中配置，不依赖网络或大模型服务。

情境只提高对应动作的出现概率。常规抽取默认 70% 从当前情境池选择、30% 从通用日常池选择，再按各池内权重随机；允许自主移动时另保留 8% 的散步覆盖概率。关闭移动仍会混合两个池中的静态动作，摸头、拖拽、扑击等手动交互照常播放。比例可在 `config/behaviors.json` 的 `contextChance` 中调整。

小窝也可以手选情境；此选择仅本次运行有效。稳定识别到新情境后，自主动作约 1 秒后重新选择；摸头、拖拽、扑击等受保护的交互动作继续播放。规则仍可能误判，支持随时补充应用和关键词。

## 动作之间的概率与日常节奏

`config/behaviors.json` 支持三层选择：先尝试当前动作的后续规则，再尝试独立计时动作，最后回到原来的情境 / 日常权重池。

- 踩奶自然结束后，有 80% 概率优先接睡觉；抱鱼犯困后为 65%；伸完懒腰后为 60%。命中后按 4:1 选择蜷睡或伸展睡，未命中则回普通动作池。
- 休息小牌子从启动起等待随机 18～22 分钟，获得一次 80% 概率的出现机会；未命中等下一周期，不会每帧重抽。这个机会间隔约 20 分钟，并不保证每 20 分钟必播。
- 摸头、拖拽、追鼠标和落地不会被计时动作打断；机会可以等到下一个安全选择点。条件后续优先，独立机会不会挤掉踩奶后的睡觉。
- 暂停时停止计时；游戏安静模式或不适用情境下跳过机会，不在切回时补播。休眠 / 卡顿恢复最多留下一个当前机会，不积攒多次。手动播放休息牌也会重新开始间隔。

规则、概率、后续动作权重、时间范围和适用情境均可改数据。计时状态仅在当前运行中保存，重启或重新加载素材后重新计时。详见[扩展指南](docs/EXTENDING.md)。

## 构建与验证

在仓库根目录用 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

重绘素材需要 Node.js 18+；只编译 C# 可以给构建脚本加 `-SkipArt`。没有 NuGet、npm 或其他第三方运行依赖。

导出动作序列和图鉴（先构建）：

```powershell
$destination = (Get-Location).Path
$app = Start-Process -FilePath './dist/Catcon-1.8.0/Catcon.exe' -ArgumentList '--export-art', ('"' + $destination + '"') -WindowStyle Hidden -PassThru -Wait
```

执行 `powershell -ExecutionPolicy Bypass -File scripts/preview-stories.ps1` 导出四个小故事，`scripts/preview-daily.ps1` 导出四个日常陪伴动作；两者均含并列动图和关键帧图。`scripts/preview-pack.ps1 -Clips "stretch,laser" -Name pack` 可按需导出任意动作的关键帧与并列动图，加 `-Publish` 直接写入 `assets/skins/mikan/`。导出后重新构建以将图鉴和序列复制到发布包。运行路径允许包含空格。测试按全部 324 个原画关键帧检查透明渲染，验证短帧 / 长帧、单次末帧保持、旧包兼容，并覆盖前台规则、受惊升级、停留避让、追逐扑击、拖拽、暂停、游戏安静模式、多屏边界及原生窗口资源释放。报告保存在 `artifacts/`。`node scripts/test-gallery.js` 验证图鉴播放逻辑；`node scripts/audit-tails.js` 按运行时图层顺序合成每一帧，检查尾巴的可见像素是否与身体相邻（防止尾巴悬空或被道具切断）；`scripts/verify-package.ps1` 验证中文和空格路径下解压运行。

花园的复核图用 `--export-garden` 导出，输出到指定目录（省略则为 exe 所在目录）：

```powershell
$destination = Join-Path (Get-Location).Path 'artifacts/garden'
$app = Start-Process -FilePath './dist/Catcon-1.8.0/Catcon.exe' -ArgumentList '--export-garden', ('"' + $destination + '"') -WindowStyle Hidden -PassThru -Wait
```

一次会得到六类图：满园 4 倍视图 `garden.png`、加了花瓣的 `garden-wind.png`、干旱缺水的 `garden-thirsty.png`、刚撒下种子的 `garden-sowing.png` 与同一帧的 12 倍局部 `garden-sowing-zoom.png`，以及每个品种一条七格生长阶段对照 `garden-stages-<species>.png`。导出用的是同一套渲染器和一份临时构造的花园状态，不读取也不修改 `garden.json` 存档，可以随时重跑；播种那张固定种在 5 号槽位（床中央、避开洒水壶和玻璃罩），只推进 0.1 秒，所以粒子聚在落点附近、位置可预期，方便逐像素复核。`README` 里的花园配图就是它的产物。

设置在 `%LOCALAPPDATA%\Catcon\settings.json`；花园存档在同目录 `garden.json`；错误日志为 `errors.log`，仅记录程序错误，不主动记录前台窗口信息。测试使用项目内独立设置目录，不影响日常配置。
