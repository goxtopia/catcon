# Catcon · 蜜柑

一只住在 Windows 桌面上的 32 × 32 像素橘白猫。透明背景、托盘常驻、鼠标互动，以及随前台应用变化的陪伴动作。

## 启动

推荐双击 `dist/Catcon-1.4.0-Setup.exe` 安装：自动释放完整文件、检查 .NET 4.8、创建启动和卸载入口。默认安装到当前用户目录；已具备运行库时无需联网和管理员权限，缺少时调用内嵌的微软 Web 安装程序补装，需要联网及管理员授权。后续直接运行新版安装包即可保留设置原位升级，旧配置会先备份；同版本支持修复安装，并阻止降级覆盖。参见 [安装与升级说明](docs/INSTALLATION.md)。

下载或复制 `dist/Catcon-1.4.0-win.zip`，**完整解压**后双击 `Catcon.exe`。也可以直接运行本仓库中的 `dist/Catcon-1.4.0/Catcon.exe`。请保留 exe 同级的 `assets`、`config` 文件夹。程序无需安装、管理员权限、Python、Node 或联网。升级时先从托盘退出旧版，再打开新版；已有位置和设置会保留。

运行环境：Windows 10 / 11，.NET Framework 4.8（Windows 10 较新版本及 Windows 11 通常已内置）。使用 Windows 自带的 .NET Framework 编译器，输出为 AnyCPU，可在 x64 / x86 系统运行。当前安装包未作代码签名。

首次打开会显示「蜜柑的小窝」。关闭小窝后，猫咪继续留在桌面。托盘图标可能在系统托盘折叠区。

## 和猫相处

| 操作 | 结果 |
| --- | --- |
| 单击猫咪 | 摸头、冒出爱心 |
| 双击猫咪 / 双击托盘 | 打开小窝 |
| 按住猫咪拖拽 | 移动位置；松开后坐好 |
| 右键猫咪 / 托盘 | 喂食、喝水、动作图鉴、暂停、置顶、退出 |
| 选择「追鼠标」 | 3 秒后锁定鼠标位置，跑近后蓄力、向前跃出并以前爪落到目标；不改变鼠标、不发送点击 |
| 鼠标快速接近 | 炸毛；24 秒内连续三次受惊会鸡母蹲 |
| 鼠标在附近停留 | 5 秒后挪开；可在设置关闭自主移动 |
| 猫咪不见了 | 托盘 → 把猫找回来 |

画布原生尺寸 **32 × 32**，默认 4 倍整数缩放（128 × 128 的透明窗口，猫咪可见部分更小），设置支持 2～6 倍。透明区域不阻挡下面的窗口；猫咪不会因普通互动抢走键盘焦点。恢复上次位置、显示大小和设置。

游戏情境默认启用安静陪伴：不自主移动、不响应鼠标惊吓；手动发起的追鼠标仍可使用。安全桌面、锁屏和独占全屏应用有系统限制；游戏推荐使用无边框窗口模式。

## 动画包

1.4.0 再增加四个日常陪伴动作，共补绘 38 个关键帧：

| 动作 | 小细节 |
| --- | --- |
| 抱着小鱼玩偶犯困 | 把布偶抱高、收紧双爪，眼皮慢慢落下，点头后又睁眼 |
| 捧着暖杯闻一闻 | 歪头看杯子、双爪托起，探头闻热气后满足地眯眼 |

新增动作沿用统一脸部库，补绘布偶、杯子、热气、铅笔、牌子与前景爪，保持独立摆尾。原有 32 个动作、22 套姿态、248 个组件不变。抱鱼、暖杯、推笔进入日常池；暖杯更偏向写代码、办公，抱鱼更偏向看视频，推笔更偏向办公休息。休息牌使用独立计时概率，不参与普通池抽取。情景仍只提高出现概率，不强制播放或弹出提醒。

1.3.0 新增四个带起承转合的小故事，共增加 40 个原画关键帧：

| 动作 | 小细节 |
| --- | --- |
| 给小垫子踩踩奶 | 左右爪交替按压，垫子对应凹下，眯眼小幅点头 |

1.2.3 以默认坐姿的正脸为角色基准，统一三分之四脸、纯侧脸和低头吃喝的头部体积、短口鼻、粉色鼻头、额头虎斑及眼睛高光。清醒时不再用单像素远眼，运动侧脸与坐姿使用同一套脸型；侧面仍只画一只可见眼睛，睡眠保留闭眼。默认坐姿本身不变，全部 152 个关键帧按同一角色展开检查，仍保留原来的摆尾、前景爪和扑击位移。

1.2.2 补绘玩球的前景拨球爪，修复被头和球挡住的问题；鸡母蹲改为收脚、立胸、圆背的紧凑姿态。28 个动作均有独立摆尾，睡觉只轻动尾尖，跑跳随姿态摆动，拖拽时尾巴自然下垂。

## 情境识别

调用 Windows API 获取前台窗口的进程名、窗口标题与范围，补充读取程序的产品名称 / 文件说明；每 2 秒采样、连续 2 次一致才切换情境。只在本地内存中匹配，**不保存窗口标题、不截图、不上传**。产品信息读取失败时继续使用其他可用线索。

| 情境 | 部分内置匹配 | 陪伴动作 |
| --- | --- | --- |
| 写代码 | Codex、WorkBuddy、VS Code、Cursor、JetBrains、Visual Studio、终端；浏览器 GitHub 等 | 监工、敲电脑、踩键盘、睡觉 |
| 看视频 | VLC、mpv、PotPlayer、哔哩哔哩；浏览器 YouTube 等 | 一起看、打哈欠、睡觉 |
| 办公 | Office、WPS、Notion、Obsidian、PDF；在线文档 | 看资料、喝水、打盹 |
| 浏览网页 | Edge、Chrome、Firefox、Brave 等 | 看书、歪头、玩毛线球 |
| 聊天 | 企业微信 / WXWork / WXWorkWeb / WeCom、微信、QQ、Telegram、Discord、飞书、钉钉、Teams 等 | 竖耳、歪头、问号偷听 |
| 玩游戏 | 常见游戏进程；游戏关键词与全屏辅助线索 | 手柄游戏、观察、喝水 |

**1.2.0 新增智能补充识别**：先匹配明确应用规则，未命中时再按进程名、产品信息和标题中的关键词分组加权。同组重复词只计一次，相同词出现在多个来源也不会重复堆分；置信分不足、前两类得分太接近或读取不到前台信息时回到 `idle`。全屏只是弱线索，不能单独把未知应用判为游戏。明确的视频网站等规则仍优先于泛化关键词。

小窝「设置」可单独开关「智能补充识别」。默认最低置信分为 68%，同时要求足够的证据得分和类别分差；这是启发式置信分，不是经过统计校准的概率。已知浏览器没有具体内容线索时仍归「浏览网页」，强线索冲突时会放弃判断。阈值、关键词、证据权重均在 `config/classifiers.json` 中配置，不依赖网络或大模型服务。

情境只提高对应动作的出现概率。常规抽取默认 70% 从当前情境池选择、30% 从通用日常池选择，再按各池内权重随机；允许自主移动时另保留 8% 的散步覆盖概率。关闭移动仍会混合两个池中的静态动作，摸头、拖拽、扑击等手动交互照常播放。比例可在 `config/behaviors.json` 的 `contextChance` 中调整。

小窝也可以手选情境；此选择仅本次运行有效。稳定识别到新情境后，自主动作约 1 秒后重新选择；摸头、拖拽、扑击等受保护的交互动作继续播放。规则仍可能误判，支持随时补充应用和关键词。

## 动作之间的概率与日常节奏

`config/behaviors.json` 支持三层选择：先尝试当前动作的后续规则，再尝试独立计时动作，最后回到原来的情境 / 日常权重池。

- 踩奶自然结束后，有 80% 概率优先接睡觉；抱鱼犯困后为 65%。命中后按 4:1 选择蜷睡或伸展睡，未命中则回普通动作池。
- 休息小牌子从启动起等待随机 18～22 分钟，获得一次 80% 概率的出现机会；未命中等下一周期，不会每帧重抽。这个机会间隔约 20 分钟，并不保证每 20 分钟必播。
- 摸头、拖拽、追鼠标和落地不会被计时动作打断；机会可以等到下一个安全选择点。条件后续优先，独立机会不会挤掉踩奶后的睡觉。
- 暂停时停止计时；游戏安静模式或不适用情境下跳过机会，不在切回时补播。休眠 / 卡顿恢复最多留下一个当前机会，不积攒多次。手动播放休息牌也会重新开始间隔。

规则、概率、后续动作权重、时间范围和适用情境均可改数据。计时状态仅在当前运行中保存，重启或重新加载素材后重新计时。详见[扩展指南](docs/EXTENDING.md)。

## 构建与验证

在仓库根目录用 PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -ExecutionPolicy Bypass -File scripts/test.ps1
```

重绘素材需要 Node.js 18+；只编译 C# 可以给构建脚本加 `-SkipArt`。没有 NuGet、npm 或其他第三方运行依赖。

导出动作序列和图鉴（先构建）：

```powershell
$destination = (Get-Location).Path
$app = Start-Process -FilePath './dist/Catcon-1.4.0/Catcon.exe' -ArgumentList '--export-art', ('"' + $destination + '"') -WindowStyle Hidden -PassThru -Wait
```

执行 `powershell -ExecutionPolicy Bypass -File scripts/preview-stories.ps1` 导出四个小故事，`scripts/preview-daily.ps1` 导出四个日常陪伴动作；两者均含并列动图和关键帧图。导出后重新构建以将图鉴和序列复制到发布包。运行路径允许包含空格。测试按全部 230 个原画关键帧检查透明渲染，验证短帧 / 长帧、单次末帧保持、旧包兼容，并覆盖前台规则、受惊升级、停留避让、追逐扑击、拖拽、暂停、游戏安静模式、多屏边界及原生窗口资源释放。报告保存在 `artifacts/`。`node scripts/test-gallery.js` 验证图鉴播放逻辑；`scripts/verify-package.ps1` 验证中文和空格路径下解压运行。

设置在 `%LOCALAPPDATA%\Catcon\settings.json`；错误日志在同目录 `errors.log`，仅记录程序错误，不主动记录前台窗口信息。测试使用项目内独立设置目录，不影响日常配置。
